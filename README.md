📚 AI Study Assistant

A simple and student-friendly web application designed to help engineering students organize their studies, practice concepts, create quick notes, and get useful study tips.

✨ Features

🎯 Study Planner

Enter a subject or topic and generate a simple study plan to organize your learning.

🧠 Quiz

Test your understanding with a 5-question quiz and check your score.

📝 Smart Notes

Enter a topic and generate short, easy-to-understand notes for quick revision.

💡 Study Tips

Get useful study tips to improve your learning and study habits.

🛠️ Technologies Used

- Python
- Streamlit

🚀 How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Run the Streamlit application.

streamlit run app.py
